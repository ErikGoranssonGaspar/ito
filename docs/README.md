# ito documentation

Provider guides are available for [Codex](./user/providers-codex.md), [Claude](./user/providers-claude.md), [OpenCode](./user/providers-opencode.md), and [Antigravity](./user/providers-antigravity.md).

Internal notes from the upstream project remain where they help explain the retained architecture. Some describe code that is still being reduced.
